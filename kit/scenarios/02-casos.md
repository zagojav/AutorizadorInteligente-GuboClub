# Casos — Chegar Certo

Todos os casos são sintéticos.

| Entrada | Resultado esperado |
|---|---|
| Dados confirmados | Manter cadastro |
| Convênio alterado | Solicitar correção assistida |
| Sem resposta antes da chegada | Permitir validação na chegada |
